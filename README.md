# ربات نمایش قیمت LAB

ربات هر ۵ دقیقه قیمت LAB را از CoinGecko دریافت می‌کند، تصویر گرافیکی را به‌روزرسانی می‌کند و همان پیام را در تلگرام ویرایش می‌کند.

## تنظیم GitHub Secrets

در مخزن به مسیر **Settings → Secrets and variables → Actions** بروید و این Secrets را بسازید:

| نام | مقدار |
|---|---|
| `BOT_TOKEN` | توکن ربات تلگرام از BotFather |
| `CHAT_ID` | آیدی کانال/گروه؛ پیش‌فرض کد `@lab_chats` است |
| `MESSAGE_ID` | شناسه عددی همان پیام تصویری که قرار است همیشه ویرایش شود |

**مهم:** ربات باید در کانال/گروه دسترسی ارسال و ویرایش پیام داشته باشد. `MESSAGE_ID` الزامی است؛ اگر خالی باشد، برنامه عمداً متوقف می‌شود تا هر پنج دقیقه پیام تکراری در گروه ارسال نشود.

## اجرای خودکار

فایل فعال گردش‌کار: `.github/workflows/lab.yml`

- اجرای زمان‌بندی‌شده: هر ۵ دقیقه (UTC)
- اجرای دستی: از تب Actions و گزینه Run workflow
- اجرای پس از هر Push به شاخه `main`
- اجرای هم‌زمان محدود شده تا دو بروزرسانی روی هم نیفتند.

## رفتار در خطا

- خطای شبکه و پاسخ‌های موقت سرور با مکث و تلاش مجدد مدیریت می‌شوند.
- قیمت نامعتبر یا قدیمی‌تر از ۱۵ دقیقه منتشر نمی‌شود.
- اگر فقط تاریخچه نمودار در دسترس نباشد، قیمت معتبر همچنان منتشر می‌شود و نمودار ممکن است خالی بماند.
- خطای Telegram یا نامعتبر بودن شناسه پیام باعث شکست واضح اجرای Workflow می‌شود.

## بررسی کد

وابستگی‌ها در `requirements.txt` هستند. پیش از اجرای ربات، Workflow دستورهای بررسی نحو پایتون و تست‌های واحد داخل `tests/` را اجرا می‌کند.

## منبع قیمت

شناسه CoinGecko در حال حاضر `lab` است. اگر API پاسخ قیمت ندهد یا دارایی دیگری با این شناسه برگردد، باید شناسه دقیق دارایی LAB در CoinGecko تأیید و سپس در هر دو endpoint قیمت و تاریخچه اصلاح شود.
