# ربات نمایش قیمت LAB

ربات قیمت LAB را از CoinGecko دریافت می‌کند، تصویر گرافیکی را می‌سازد و **همان پیام تصویری ثابت** را در تلگرام ویرایش می‌کند؛ پیام تازه و تکراری نمی‌فرستد.

## تنظیم GitHub Secrets

در مخزن به مسیر **Settings → Secrets and variables → Actions** بروید و این Secrets را ثبت کنید:

| نام | مقدار |
|---|---|
| `BOT_TOKEN` | توکن ربات تلگرام از BotFather |
| `MESSAGE_ID` | شناسه عددی پیام تصویری ثابتی که باید ویرایش شود |
| `CHAT_ID` | آیدی کانال/گروه؛ اگر ثبت نشود مقدار پیش‌فرض `@lab_chats` استفاده می‌شود |

ربات باید عضو گروه/کانال باشد و اجازه ارسال و ویرایش پیام داشته باشد. پیام مبنا را یک بار در گروه ارسال کنید و شناسه همان پیام را در `MESSAGE_ID` بگذارید. اگر این Secret موجود نباشد یا عددی نباشد، Workflow پیش از اجرا با خطای روشن متوقف می‌شود.

## زمان‌بندی و محدودیت دقت

فایل فعال: `.github/workflows/lab.yml`

- زمان‌بندی درخواستی: هر ۵ دقیقه با cron یعنی `*/5 * * * *` (UTC).
- اجرای دستی از تب Actions نیز فعال است.
- اجرای push به شاخه `main` هم برای تست و انتشار تغییرات فعال است.
- اجرای هم‌زمان جلوگیری می‌شود تا دو ویرایش روی هم نیفتند.

**نکته مهم:** زمان‌بندی GitHub Actions تضمین لحظه‌ای ندارد؛ GitHub ممکن است اجرای زمان‌بندی‌شده را چند دقیقه دیرتر شروع کند یا در شرایط شلوغی به تأخیر بیندازد. بنابراین فقط با cron گیت‌هاب نمی‌توان «دقیقاً در هر دقیقه پنجم و بدون حتی یک تأخیر» را تضمین کرد. این تنظیم بهترین تلاش ۵ دقیقه‌ای روی GitHub-hosted Actions است.

## کنترل خطا

- درخواست‌های GET با retry و timeout انجام می‌شوند.
- قیمت نامعتبر یا قدیمی‌تر از ۱۵ دقیقه منتشر نمی‌شود.
- اگر تاریخچه نمودار در دسترس نباشد، قیمت معتبر همچنان منتشر می‌شود.
- ویرایش تلگرام برای خطاهای موقت شبکه، 429 و 5xx تا ۴ بار تلاش می‌کند و زمان انتظار اعلام‌شده از سمت تلگرام را رعایت می‌کند.
- Workflow در صورت شکست برنامه تا ۳ بار کل اجرا را دوباره امتحان می‌کند و در پایان با وضعیت قرمز و لاگ روشن شکست می‌خورد.
- پیام ثابت ویرایش می‌شود؛ اجرای مجدد باعث ساخت پیام‌های تکراری نمی‌شود.

## منبع قیمت

شناسه CoinGecko فعلی `lab` است. اگر این شناسه متعلق به دارایی موردنظر نباشد یا CoinGecko پاسخ معتبر ندهد، انتشار متوقف می‌شود؛ شناسه توکن باید از صفحه رسمی دارایی CoinGecko تأیید شود.

## نمایش

قیمت با ۵ رقم اعشار، متن فارسی، تاریخ شمسی و ساعت ایران نمایش داده می‌شود. نمودار ۲۴ ساعته در صورت دریافت تاریخچه معتبر رسم می‌شود.
